ពិនិត្យ និងកែអក្ខរាវិរុទ្ធខ្មែរ និង English ផ្ទាល់ក្នុង Microsoft Word ហើយបកប្រែ English ⇄ ខ្មែរ ដោយប្រើ Google Gemini (API Key ឥតគិតថ្លៃ)។

១. យក Gemini API Key (ឥតគិតថ្លៃ)

  1. ចូល aistudio.google.com/apikey ដោយ Gmail
  2. ចុច Create API key ហើយចម្លង Key (ចាប់ផ្ដើមដោយ AIza…)

២. ដំឡើងក្នុង Word

Word for Windows / Mac (Microsoft 365)
  1. ទាញយក manifest.xml ខាងលើ
  2. ក្នុង Word៖ Home → Add-ins (ឬ Insert → Get Add-ins) → My Add-ins
  3. ចុច Upload My Add-in (ឬ Advanced… → Upload) → ជ្រើស manifest.xml
  4. ប៊ូតុង Khmer Check នឹងបង្ហាញនៅលើ Home tab
Word Online (office.com)
  1. បើកឯកសារ → Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in
  2. ជ្រើស manifest.xml

៣. ប្រើ

  1. ចុច Khmer Check → ⚙ កំណត់ → បិទភ្ជាប់ API Key → «រក្សាទុក»
  2. ពិនិត្យអក្ខរាវិរុទ្ធ៖ ជ្រើសអត្ថបទ ឬ «ឯកសារទាំងមូល» → ចុច «ពិនិត្យ» → ពាក្យខុសត្រូវគូសពណ៌ក្រហមស្រាលក្នុងឯកសារ → ចុច «កែ» ឬ «កែទាំងអស់»
  3. បកប្រែ៖ ជ្រើសអត្ថបទ → ចុច «បកប្រែ» → «ជំនួសអត្ថបទ» ឬ «ដាក់ខាងក្រោម»
